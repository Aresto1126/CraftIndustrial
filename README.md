# CraftIndustrial
サティスファクトリーやマイクラで何を作って何を作っていないかなど、自動化しているものとそうでないものを管理する。また、完成物の必要数を入力すると登録済みの中間素材や元の資源数を自動で計算、確認することができる。

## 使い方
スマホのブラウザで動く、サーバー不要のPWAです。データは端末内（localStorage）にのみ保存されます。

- **アイテム**: 資源・中間素材・完成物を登録。レシピ（1回で得られる数と材料）を入れると中間素材として扱われ、空なら原料扱い。バッジをタップで `未作成 → 手動 → 自動化` を切り替え。ゲーム別・状態別に絞り込み可能。
- **計算**: 完成物と必要数を指定すると、中間素材・原料の必要量、レシピ回数、各素材の作成/自動化状況を表示。
- **設定**: JSONバックアップの書き出し/読み込み、サンプルデータ追加。

### 起動・スマホで使う
```
python3 -m http.server 8000   # 静的ファイルを配信できれば何でも可
```
HTTPSで公開（GitHub Pages等）してスマホで開き、「ホーム画面に追加」するとオフラインでも動作します。
`file://` で直接開いても動作します（オフラインキャッシュのみ無効）。

### テスト
`node calc.test.js`
